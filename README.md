# Neon Tape Studio

Static WEB Technologies 1 midterm website for a fictional indie recording studio.

## Pages

- `index.html` - home page and studio concept
- `workflow.html` - recording workflow
- `equipment.html` - equipment table
- `booking.html` - booking form

## Teamwork Plan

- Alikhan: home page and booking page
- Abay: workflow page and equipment page

Each teammate should make commits from their own GitHub account for the pages they are responsible for. This is required by the teamwork criterion.

## Criteria Checklist

- 4 pages for a 2-person team
- Shared navigation on every page
- Consistent custom style across all pages
- Semantic HTML structure
- Bootstrap 5 grid, navbar, buttons, table and form controls
- CSS Grid, Flexbox and custom media queries
- At least one form and one table
- Responsive breakpoints for 375px, 768px and 1280px layouts

After pushing to GitHub, enable GitHub Pages from the repository settings and include both the repository URL and deployed website URL in the report.
